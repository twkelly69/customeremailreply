# 規則盤點：回答客戶信件

模組：rule-inventory（capability-architecture-interviewer，Rule 章第一個模組）
訪談日期：2026-09-06

規則跟做法的差別：做法是這樣做比較好，違反了頂多效果差一點。規則是不可以這樣做，違反了會出事。好的規則寫出來是不得或必須開頭，而且可以判斷有沒有違反。

本模組全部繞道問，六題皆為側面提問，未直接詢問清單。所有規則句子均由承辦 PM 的回答重組並經其逐條確認。

## 違反的偵測方式

| 規則 | 誰會發現 | 時機 |
|---|---|---|
| R1、R2 | cost 增加，或 CRA 反應 | 事後。代價已經產生 |
| R3、R5、R6 | 承辦 PM 核准時攔到。她沒看到就是客戶抓到 | 送出前或送出後 |
| R4 | 稽核時，或 CRA monitoring 時 | 事後，週期性 |
| R7、R8 | 未定 | 未定 |

R1 與 R2 這一組值得標記：規則的作用是避免成本增加，但違反的偵測要等成本先發生。

## 診斷

### 輕重排序

| 等級 | 規則 |
|---|---|
| 會出事 | R1、R2、R3、R4、R5、R6 |
| 會被糾正 | 空 |
| 會不好看 | R7、R8 |

R1 與 R2 原先列為會被糾正，經承辦 PM 更正上移，理由是 cost 增加是實質損失。

八條裡六條會出事。這不是一份規矩很多的清單，是一份每條都有代價的清單。

### 依模組規定必須指出的一件事

**有四條會出事等級的規則，現在完全沒有寫下來，也就是 R1、R2、R5、R6。**

其中 R5 與 R6 正是 PD 在核准對外回覆時眼睛在掃的兩件事。也就是把關的標準本身沒有文件。

### 五類分佈檢查

| 類別 | 條數 | 狀態 |
|---|---|---|
| Business | R1、R3、R5、R6，共四條 | 充足 |
| Compliance | R4，共一條 | 偏少 |
| Style | R7、R8，共兩條 | 充足 |
| Workflow | R2，共一條 | 偏少 |
| Safety | 零條 | 空 |

**Safety 類是空的。** 依模組定義，這一類空著通常代表：沒有人想過哪些東西一旦流出去或被刪掉就救不回來，或者想過但沒有把它當成規則寫下來。

本次訪談其實已經出現數個 Safety 類的素材，包含 XRIM 的 Risk 與 Issue 被客戶看到會有事、客戶行為模式被本人看到更糟、記錄依法規不得刪除、以及對外送出是第一個不可逆動作。但這些在六題繞道提問中都沒有被承辦 PM 以規則的形式講出來。

Compliance 只有一條也偏少，同樣需要在 rule-types 補問。

## 口傳規則清單

沒寫在任何地方、只靠交代的規則。

| 規則 | 新人沒被交代到會怎麼樣 |
|---|---|
| R1 擋下不必要的 visit 變更 | 排程被改動，cost 增加，要等成本發生才知道 |
| R2 不得直接答應廠商要求 | 直接答應，這正是 memory-layer 記載的失敗劇本，承諾了做不到 |
| R5 不得超出 scope | 對外承諾超出範圍，要收拾 |
| R6 不得承諾做不到的事 | 同上，且踩的是對外不可逆動作 |
| R7 不得使用保證、一定 | 用語過度承諾 |
| R8 不得指稱對方的錯 | 對外關係受損 |

六條全部靠交代。其中 R5、R6 沒有人說得出是誰定的，也就是既沒有文件也沒有明確的規則擁有者。

## 缺口

這一輪最模糊的是 R5、R6、R7、R8 的可否修改欄，四項皆為未定。

原因照實記錄：承辦 PM 表示說不出來是誰定的，一直都是這樣。沒有決定者就無法回答誰有權修改。

導致的後果：rule-governance 模組要處理誰有權建立、修改、廢除規則。四條規則沒有擁有者，其中兩條是會出事等級，代表現在沒有人有權說這兩條該怎麼改，也沒有人負責讓它們被遵守。

第二個缺口是 R7、R8 的偵測方式未問到，因此無法判斷違反用語規則時是否真的會被攔下。

## 給實作的建議

依模組規定，本節只標記哪幾條光靠文字規則擋不住，不說明手段是什麼。

| 規則 | 光靠文字擋得住嗎 |
|---|---|
| R1 | 擋不住。偵測要等成本發生，文字提醒無法在事前攔截 |
| R2 | 擋不住。有疑問三個字沒有門檻 |
| R5 | 擋不住。目前唯一的把關是承辦 PM 一個人看 |
| R6 | 擋不住。同上，且它已經在 memory 章被記為實際發生過的失敗 |
| R3 | 文字規則可能足夠。已寫進 email SOP，且核准時攔得到 |
| R4 | 文字規則可能足夠。已寫進 protocol 與 SOP，且有稽核 |
| R7、R8 | 未定。偵測方式未知 |

四條標記為擋不住的規則，正好就是四條會出事而且沒有寫下來的規則。
